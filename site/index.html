Service Sunsets

AWS retires services in batches. This page lists those from 2025 to 2027, plus changes from 2024 that still apply: what each one did, when it ends, where to move, and the AWS page that says so.

What the statuses mean

Shut down
Gone. It no longer works.
End date set
Works until the date, then stops.
No new customers
Runs for existing customers and gets no new features. No end date yet.
Renamed
The same service under a new name.
Reversed
AWS cancelled a planned retirement.
